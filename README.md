# 쎈Clean 내려받기

교사 PC 안심 점검 도구 **쎈Clean** 설치 파일을 올리는 곳입니다.

- 최신 버전: [Releases → Latest](https://github.com/smchosmart-beep/senclean-releases/releases/latest)에서 `SenClean-Setup-<버전>.exe`를 받아 실행하세요.
- 1.0.0부터는 쎈Clean이 새 버전을 스스로 알려 줍니다(로고를 누르거나 설정 → 쎈Clean 업데이트).
- 모든 설치 파일은 쎈Clean 서명(latest.yml의 senSignature)이 맞을 때만 자동 업데이트로 설치됩니다.

## 저작권과 이용약관

쎈Clean는 저작권법의 보호를 받는 프로그램입니다. 1.2.0부터 **쎈Clean 이용약관**이 적용됩니다(설치 화면과 프로그램 안 [이용약관 보기]에서 볼 수 있습니다).
- 설치 파일은 이 페이지에서만 받아 주세요. 다른 곳(웹하드, 메신저 단체방, 다른 저장소 등)에 다시 올리지 말고, 이 주소를 안내해 주세요.
- 허락 없이 수정·개작하거나, 설치 파일·프로그램 파일을 AI 서비스에 올려 분석하게 하거나 비슷한 프로그램을 만들게 할 수 없습니다.
- 함께 들어 있는 오픈소스 구성 요소는 각자의 라이선스를 따릅니다.
